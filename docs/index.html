validate_preconditions_node

Paso 1 del pipeline — Evaluación previa a inferencia

LangGraph Async Node
🎯 Objetivo y Justificación Técnica
Comprueba el estado de facturación del cliente, listas negras de usuarios y horarios de sueño antes de realizar cualquier llamada a Anthropic Claude. Previene consumo innecesario de tokens (Zero Token Waste).
⚠️ Gotcha de Producción Resuelto
Si un cliente agota su cuota de mensajes a mitad de mes, el webhook entrante se aborta en menos de 2ms sin invocar al modelo, conservando el buffer acumulado para cuando reactive su suscripción.
📥 Input State (Consumed)
user_id, client_id, client_profile, combined_input_text
📤 Output State (Produced)
should_abort: bool, abort_reason: str, is_sleeping: bool
