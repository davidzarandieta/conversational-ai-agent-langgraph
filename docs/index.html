1. validate_preconditions_node

Chequeo estricto previo a llamada a LLM (Control de costes y descanso)

LangGraph Async Node
🎯 Objetivo Técnico y Comportamiento
Comprueba el saldo del cliente, listas de exclusión de usuarios y horarios de descanso antes de invocar la API de Anthropic Claude. Previene el consumo de tokens en turnos inválidos.
💡 Valor para el negocio: Garantiza que si un lead habla de madrugada o el saldo está agotado, no se gastan tokens ni se envía nada inoportuno.
⚡ Mutación de Estado (State Diff)
Input: user_id, client_id, client_profile
Output: { should_abort: False, is_sleeping: False }
Ver en GitHub ↗ 
async def validate_preconditions_node(state: SetterState) -> Dict[str, Any]:
    client_profile = state.get("client_profile")
    billing = compute_billing_status(client_profile)
    if billing.get("is_locked", False):
        activate_billing_lock_for_client(client_id)
        return {"should_abort": True, "abort_reason": "billing_locked"}
    return {"should_abort": False, "is_sleeping": False}
